# Elaj App 🏥

تطبيق محمول للبحث عن الأدوية وتوصيلها.

## 🚀 التقنيات المستخدمة
* **Frontend:** Flutter
* **Backend:** Node.js / Express
* **Database:** MongoDB / Supabase

## 📌 الميزات الرئيسية
* البحث عن الأدوية في الصيدليات.
* تقديم طلبات التوصيل المباشر.

flutter pub get
